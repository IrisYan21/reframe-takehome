# Reframe Take-home Challenge

User research for Reframe's onboarding: a research plan, analysis passes, and the raw data behind them.

## Contents

- `01-user-research-plan.md`: research plan
- `pass1-*`: first-hand insights, questions asked, summary
- `pass2-*`: coded app-review findings, frequency tables, quote bank
- `pass3-*`: target user profile, community threads
- `pass4-comparison-table.md`: competitor comparison
- `*_onboarding_screens.csv`: screen-by-screen onboarding breakdowns (Reframe, Noom, Cutback, Finch, Sunnyside)
- `data/`: scraped reviews (App Store, Google Play, Trustpilot), coded reviews, Reddit posts, and the scripts used to scrape and analyze them (`scrape_apple.py`, `scrape_google_play.mjs`, `code2.py`, `freq.py`, `tables.py`, `quotes.py`)
